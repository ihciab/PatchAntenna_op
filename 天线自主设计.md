题目：Learning to Reason over Physics States for Autonomous Electromagnetic Design

解决的问题是：
> How can an agent autonomously form reusable physical abstractions and iteratively discover new scientific designs in a continuous geometric space?

# 核心贡献

### Contribution 1

Geometry Program Synthesis for continuous EM design.
We propose a geometry program synthesis framework based on a domain-specific design language.

We introduce a physics-aware state abstraction mechanism that converts complex electromagnetic fields into symbolic reasoning states.


### Contribution 3

State-Action-Outcome Scientific Memory.
We develop a self-evolving scientific memory based on state-action-outcome trajectories.

### Contribution 4

Open-ended Scientific Design Agent.

九、核心创新4
